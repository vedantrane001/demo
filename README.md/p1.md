 📊 Sales Performance Dashboard

## 🧠 Objective
This project analyzes sales data to identify trends, top-performing products, regions, and sales representatives.  
The goal is to create a dashboard that helps business users make data-driven decisions.

## 🛠️ Tools & Technologies
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- SQL (for querying and cleaning data)
- Power BI / Tableau / Streamlit (for dashboard visualization)
